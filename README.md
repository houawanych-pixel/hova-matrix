# Hova Matrix

A multi-world home for games, stories, artwork and creative projects.

## Website

The site is static HTML, CSS and JavaScript. Open `index.html` locally or publish the repository root with GitHub Pages.

### Enable GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, **main**, **/(root)**, then Save.

Expected address after publishing: https://houawanych-pixel.github.io/hova-matrix/

## Included

16 pages, project branches, early beta launch links, themed world sections, horizontal galleries, image enlargement, shop category filters and a local permission-request draft.

Evertrail and MG launch at their existing game URLs. MG is also featured under HOVAGI. Concept artwork is not current gameplay footage.

EchoVision and I Odin show only their names and under-construction status. Private planning documents and PRDs are not included.

## Pending content

Merchandise checkout, donations, social channels, permission contact delivery, music and video uploads remain unconfigured. The permission form only creates a local downloadable draft; it does not send data or grant approval.

## Validation

All local page links, assets and anchors checked. JavaScript syntax checked. Beta launch pages returned their expected titles. Browser interaction and mobile visual review remain pending; gameplay has not been playtested in this website pass.
